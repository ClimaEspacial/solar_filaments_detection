# CleanElegant Beamer Theme

The **CleanElegant Beamer Theme** is a minimalist and elegant LaTeX template tailored for academic and scientific presentations.

-   Overleaf: https://www.overleaf.com/latex/templates/cleaneasy-beamertheme/
-   CTAN: https://ctan.org/pkg/beamertheme-cleaneasy
